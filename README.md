# AI POC Projects

This repository contains Proof-of-Concept (POC) projects
for evaluating Artificial Intelligence and Generative AI
solutions.

## Objectives

- Evaluate AI/ML technologies
- Develop Generative AI POCs
- Experiment with RAG solutions
- Experiment with AI Agents
- Evaluate Azure AI services
- Document architecture and findings

## Repository Structure

- src - Application source code
- notebooks - Jupyter notebooks
- data - Sample datasets
- config - Application configuration
- tests - Testing
- docs - Architecture and documentation
